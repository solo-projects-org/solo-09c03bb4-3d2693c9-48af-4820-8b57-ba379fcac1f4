1. 导入日收盘价底表（一次导入，只增不改）

每行一条，支持 YYYY-MM-DD,收盘价分 或 JSON {"trade_date":"...","close_cents":1000}；同日期同价重复跳过，异价整批退回。

2. 导入拆并股公告（编号 / 修订 / 生效日 / 旧股数 → 新股数）

每号取最高修订；同号同版原样重送沿用原公告，异文退回；更高修订即更正。
